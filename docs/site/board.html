Les workflows

Chaque workflow est regroupé en briques. Le jeton suit son scénario : les boucles quand une condition n'est pas remplie, vos décisions, les refus des gardes, les sous-agents qui partent et reviennent. Lisez-le d'une traite ou pas à pas.

Lisez le workflow d'une traite, ou pas à pas avec les flèches : ses boucles, vos décisions et les refus des gardes.

1

Cadrer

savoir quoi faire avant de le faire

  1. /kwa:brainstormexplorer, comparer deux ou trois approches, écrire une spec courte
  2. validationvous approuvez la spec
  3. /kwa:plandécouper en tâches de quelques minutes
2

Faire

sur une branche, par petites tâches

  1. guard-writepas de code produit sur main
  2. /kwa:start-devissue, branche et worktree
  3. /kwa:agentsun implémenteur par tâche
3

Prouver

une sortie fraîche, pas une impression

  1. /kwa:tddun test qui échoue, puis le code
  2. /kwa:verifyles vérifications du projet, sorties citées
4

Relire

un regard neuf qui ne peut rien modifier

  1. kwa:reviewerrelit en lecture seule
  2. /kwa:review-feedbacktrier les constats avant d'en appliquer un
5

Livrer

chaque publication est une décision

  1. pushvous autorisez la publication de la branche
  2. /kwa:shipPR liée à son issue, avec la preuve
  3. fusionvous donnez le feu vert
6

Capitaliser

la session suivante part de ce qu'on a appris

  1. /kwa:learnranger chaque leçon au bon endroit
  2. /kwa:handoffun document de reprise pour la session suivante
