Kwa · Kit de Workflows Agentiques · v

Un kit de workflows agentiques pour le développement

Un socle de process de développement pour travailler avec des agents de code : règles, garde-fous, skills, mémoire et workflow, les mêmes sur chaque projet. Ce qui change d'un projet à l'autre tient dans un fichier de politique.

Workflow agentique : un enchaînement d'étapes proposé à l'agent. Il choisit comment avancer, mais les gardes imposent les points de passage : pas de code sur main, pas de PR sans issue, pas de fusion sans preuve. Ce qui est imposé, ce qui est suggéré

Pourquoi ce projet

Un support pédagogique, en français

Kwa montre, avec de vrais fichiers qui tournent, comment encadrer un agent de code. Il est fait pour apprendre et pour partager, avant d'être fait pour être installé.

Apprendre

Chaque pièce est lisible, testée et expliquée : règles, garde-fous, skills, mémoire. Trois parcours de formation vont de la culture de l'IA générative au harness.

En français

Presque tout ce qui existe sur le sujet est en anglais. Les skills, les règles et la documentation sont ici en français, pour celles et ceux que l'anglais freine.

Partager

Des bonnes pratiques issues de l'usage et d'idées reprises à d'autres projets, toujours créditées. Les retours et les corrections sont bienvenus.

Arborescence

Ce que Kwa ajoute, et où

Votre projet ne reçoit que de la configuration ; skills, gardes et hooks vivent dans le plugin, installé une fois par machine. Ouvrez un dossier pour voir ce qu'il contient. Chaque ligne renvoie à son code source ; les skills et les gardes renvoient aussi à la carte. Décochez un module pour voir ce qui disparaît.

Modules

stack-prisma et stack-scaleway n'ajoutent aucun fichier : ils règlent seulement la politique.

Survolez un module pour voir son rôle ; décochez-le pour voir ce qui disparaît.
